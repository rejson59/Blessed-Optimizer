✦ DOBRZE WIEDZIEĆ

Jasne odpowiedzi.
Bez drobnego druku.

Czy ta strona naprawdę optymalizuje mój komputer?+

Nie — to interaktywny prototyp. Sama strona nie skanuje urządzenia ani nie zmienia Windows. Aplikacja Windows jest osobnym programem, a jej instalator pobierzesz z przycisku u góry, gdy będzie dostępny w GitHub Releases.

Czy aplikacja zagwarantuje niższy ping lub więcej FPS?+

Nie da się obiecać tego każdemu. Ping zależy m.in. od sieci i serwera, a liczba klatek od komputera, gry i ustawień. Aplikacja nie mierzy FPS; test ping uruchamiasz osobno, na własne żądanie.

Gdzie pobiorę aplikację?+

Użyj przycisku u góry strony. Jeśli najnowsze wydanie GitHub zawiera instalator, przycisk pobierze plik .exe; w przeciwnym razie otworzy listę wydań zamiast prowadzić do niedziałającego linku.
